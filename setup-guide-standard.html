01
WHERE IS MY DATA データはどこに？

このアプリは「買い切りのHTMLファイル1枚」です。インストールもログインもなし。アカウントもいりません。その代わり、データの居場所が普通のアプリと少し違うので、最初にここだけ説明させてください。

📦
レシピのデータ
アプリを開いたブラウザの中（localStorage）に保存されます。サーバーには送られません
🔌
ネット接続
基本いりません。オフラインでも書ける・読める・編集できる
☁️
バックアップ先
自分のGoogleドライブ等にJSONで保存。アプリ側はクラウドを持ちません
🔗
デバイス間で共有
エクスポート→別デバイスでインポート、という手動方式
つまり
データはぜんぶあなたのブラウザの中にあります。だから、
・ ブラウザのキャッシュを消すとレシピも消えます
・ 別のブラウザ／別の端末で開くと、そこは空っぽです
・ その代わり、サービス終了や課金変更でデータが人質になることはありません
大事なレシピは、セクション07の手順で定期的にバックアップを取ってください
02
WHAT YOU CAN DO できること

スタンダード版は、レシピを自分の手で書いて貯めていくシンプルなレシピ帳です。よけいな機能はなし。書いて、探して、交換する。それだけにちゃんと効きます。

✏️
手入力で書く
レシピ名・材料・作り方・タグ・メモ・出典を自由に記録
🔍
検索・タグで探す
増えてきても、キーワードやタグですぐ見つかる
📨
テキストから読み込み
送られてきたレシピテキストを貼るだけでフォームに自動展開
📤
レシピを交換
このアプリ同士なら、まるごとそっくり送り合える
🔒
完全ローカル動作
レシピはブラウザ内のみに保存。詳しくはセクション01へ
💸
追加費用ゼロ
APIキーもアカウントも不要。買ったあと一切お金はかかりません
AI版との違い
スタンダード版には、レシピのスクショをAIが自動で読み取る機能はありません。レシピは手で入力します。「写真を貼るだけで自動入力」を使いたい場合はAI版（別売）をご検討ください。なお、入力以外の機能（検索・タグ・交換・バックアップ）は両版とも同じです。
03
GETTING STARTED はじめかた

準備はほぼありません。ダウンロードしたファイルを開けば、それでもう使えます。

1
ファイルを開く
ダウンロードした my-recipe-book-with-u-standard.html をブラウザで開きます。Safari / Chrome / Edge どれでもOK
2
ホーム画面に追加しておくと便利
スマホなら、ブラウザの共有メニューから「ホーム画面に追加」。アプリのように1タップで開けるようになります
3
右上の「＋ ADD」で最初のレシピを追加
これだけ。アカウント登録もログインも何もいりません
開いたブラウザ＝あなたのレシピ帳です。いつも同じブラウザ（同じアプリのファイル）で開くようにしてください。違うブラウザで開くと、そこは空っぽの別のレシピ帳になります。
04
WRITE A RECIPE レシピを書く

このアプリの主役。1品ぶんを手で書いて保存します。全部の欄を埋める必要はありません。レシピ名だけでも保存できます。

1
右上の「＋ ADD」をタップ
「レシピを追加」画面が開きます
2
レシピ名を入力
いちばん上の欄に。例：「お母さんの肉じゃが」。ここだけは入れてあげてください
3
材料を足していく
「＋ 材料を追加」を押すと、材料名と分量の欄が1行ずつ増えます。必要なぶんだけ追加
4
作り方・タグ・メモ・出典を入力
作り方は1行に1ステップ。タグは入力してEnterで追加。メモや出典（URLなど）は任意です
5
「💾 保存する」をタップ
これで一覧に追加されます。あとからいつでも「✏️ 編集」で直せます

入力欄の中身

追加画面には、こんな欄があります。埋めたいところだけ埋めればOKです。

レシピを追加
レシピ名
例：お母さんの肉じゃが
材料（＋ 材料を追加で増やす）
じゃがいも　3個
玉ねぎ　1個
牛こま　200g
作り方（1行 = 1手順）
1. 材料を切る
2. 炒める
3. だしと調味料を入れて煮る
🏷 タグ（Enterで追加）
例：和食、お弁当...
メモ（任意）
気づいたこと、アレンジ、失敗したことなど...
URL・出典（任意）
https://... インスタ、レシピサイトなど
完璧に書こうとしなくて大丈夫。あとから「✏️ 編集」で何度でも育てられます

📨 手で打たずに入れる方法もある

誰かがこのアプリから送ってくれたレシピなら、手打ちは不要です。追加画面のいちばん上に「テキストから読み込む」欄があり、もらったテキストを貼って「📥 フォームに読み込む」を押すと、各欄に自動で入ります。

この使い方はセクション06でくわしく説明します。

05
FIND & ORGANIZE 探す・整理する

レシピが増えてきたら、探す・整える機能の出番です。

🔍
キーワード検索
画面上の「SEARCH RECIPES...」に入力。レシピ名や材料から絞り込めます。×ボタンで一発クリア
🏷
タグで絞り込み
「和食」「お弁当」などのタグをタップすると、そのタグのレシピだけ表示
↕️
タグの並べ替え
タグはドラッグで並べ替え可能。よく使うタグを手前に
✏️
編集・削除
レシピを開いて「✏️ 編集」で修正、「🗑 削除」で消去
タグの編集
タグを長押しすると名前を編集できます。あとから「夕飯」を「主菜」に変える、みたいな整理もできます。
タグは最初から完璧に決めなくてOK。使いながら「これ便利だな」を足していくのがおすすめ
06
SWAP RECIPES レシピを交換する

このアプリ同士なら、レシピをそっくりそのままやり取りできます。LINEでメッセージを送る感覚で、レシピ名・材料・作り方・メモ・出典まで、まるごと相手のアプリに届きます。

家族や友人がこのアプリを持っていれば、「うちのカレーのレシピ送るね」が、手打ちなし・写真撮り直しなしでできます。AI版とスタンダード版のあいだでも、問題なくやり取りできます。

仕組み
シェアボタンを押すと、レシピが整形されたテキストに変換されます。そのテキストをLINE・メール・メモアプリ等で送り、受け取った人はアプリの追加画面に貼り付けるだけ。サーバーを経由しないので、どこにも履歴が残りません。

📤 送る側

1
送りたいレシピを開く
一覧から送りたいレシピをタップ
2
「📤 シェア」ボタンをタップ
整形済みのレシピテキストが表示されます
3
「📋 テキストをコピー」をタップ
クリップボードにコピーされます
4
LINE・メール・メモアプリ等に貼り付けて送信
いつも使っている連絡ツールでそのまま送れます
貼り付ける場所はどこでもOK。LINEでもDiscordでもメールでも、テキストが通ればどこでも

📥 受け取る側

アプリを持っていれば、受け取ったテキストをそのまま自分のレシピ帳に取り込めます。

1
もらったレシピテキストをコピー
LINEやメールの本文を長押しして全選択 → コピー
2
アプリで「＋ ADD」をタップ
追加画面の一番上に「📨 テキストから読み込む」欄があります
3
欄にペースト → 「📥 フォームに読み込む」
レシピ名・材料・作り方・メモ・出典が自動でフォームに展開されます
4
内容を確認して「💾 保存する」
受け取ったまま保存してもいいし、自分好みに調整してから保存してもOK

シェアテキストの見た目

こんな形式でコピーされます。アプリを持っていない人が受け取っても、そのまま読めます。

🍳 大根の辛子漬け ──────────────────── 🥕 材料 ・大根　1/2本 ・塩　大さじ1 ・砂糖　大さじ3 ・辛子粉　大さじ1 👩‍🍳 作り方 1. 大根を拍子木切りにする 2. 塩をまぶして30分おく 3. 水気を絞り、砂糖と辛子粉を混ぜる 4. 保存容器に入れて一晩漬ける 💬 コツ 辛子の風味は一晩おくとマイルドになります 📌 出典：母のレシピ

こんな使い方ができます

👩‍👧
母から娘へ
「実家の味」を口頭じゃなくテキストで受け継ぐ。メモも出典も一緒に届く
👯
友達同士で交換
「この前食べた美味しかったやつ」を、次の日にはお互いのレシピ帳に
🏠
家族で共有
夫婦・親子で同じレシピ帳を育てる。誰かが追加したら送り合うだけ
✍️
アレンジして返す
受け取ったレシピを自分好みに調整して「うちはこうしたよ」と送り返せる
シェアするのはテキストだけです。レシピに設定した写真は送られません。画像が必要な場合は別途LINE等で送ってください。
07
BACKUP / EXPORT / IMPORT バックアップと引っ越し

レシピが増えてきたら、バックアップを取ってください。別のスマホや新しいPCに引っ越しする時もこの機能を使います。

このアプリ自体はクラウドを持たないので、保存先はあなた自身のクラウドストレージ（Googleドライブ・iCloud Drive・Dropbox など、普段使っているもの）を使います。

保存形式
・ JSONファイル … アプリに読み戻せる引っ越し用データ
・ バックアップHTML … アプリがなくても開ける閲覧専用のレシピ集

📤 エクスポート（書き出す）

今のレシピをファイル1個にまとめて書き出します。

1
設定を開く
画面下の「⚙ 設定」をタップ
2
「📤 レシピをエクスポート（JSONファイル）」をタップ
「データのバックアップ」欄にあります
3
保存先を選ぶ
my-recipe-book-YYYY-MM-DD.json というファイル名で、Googleドライブ等クラウドに保存しておくのがおすすめ
月1回バックアップ、くらいの気持ちでOK。レシピを大量に追加した日も忘れずに

📥 インポート（読み戻す）

書き出したJSONファイルを読み込んで、アプリを元の状態に戻します。別の端末への引っ越しもこの手順です。

1
新しい端末でアプリを開く
引っ越し先の端末で my-recipe-book-with-u-standard.html を開いて、設定へ
2
「📥 レシピをインポート（JSONファイル）」をタップ
ファイル選択ダイアログが開きます
3
JSONファイルを選ぶ
クラウドに保存したJSONを選択。読み込み完了のメッセージが出れば成功
インポートすると既存データはすべて上書きされます。元の端末のレシピと新しいファイルのレシピを合体させたい場合は、先に元の端末でエクスポートしてから、JSONファイルをテキストエディタで編集する必要があります（上級者向け）。

📄 バックアップHTML（見るだけ版）

レシピを「アプリなしでも開ける1枚のHTML」として書き出す機能です。スマホのブラウザで開けば、編集はできないけど、読むだけなら誰でもできます。

👀
閲覧専用
追加・編集はできない。見るだけ
📲
端末を問わない
ブラウザさえあれば開けるので、家族と共有しやすい

設定 → 「📄 バックアップHTML（見るだけ版）を保存」から書き出せます。普段使いのバックアップはJSON、共有用はHTML、と使い分けるのがおすすめ。

どこに保存する？

☁️
Googleドライブ
無料15GB。Googleアカウントがあればすぐ使えます
🍎
iCloud Drive
iPhoneユーザーなら無料枠5GBで十分足りる
📦
Dropbox など
普段使っているクラウドで全く問題なし
💾
端末内だけはNG
端末を壊すと一緒に消えるので、必ずクラウドへ
どのクラウドを使っても、保存するのはただのJSONファイルです。特別な設定は何もいりません
08
FAQ よくある質問
Q
アカウント登録やログインは必要ですか？
いりません。ファイルを開けばすぐ使えます。インターネット接続も基本的に不要です。
Q
買ったあと、お金はかかりますか？
かかりません。APIキーもサーバーも使わないので、追加費用はゼロです。
Q
スマートフォンでも使えますか？
はい。Safari / Chrome いずれでも動作します。ホーム画面に追加しておくと、アプリのように開けて便利です。
Q
写真をAIに読み取ってもらうことはできますか？
スタンダード版にはAI読み取り機能はありません。レシピは手で入力します。その機能が必要な場合はAI版をご検討ください。
Q
アプリを持ってない人にレシピをシェアできますか？
送ることはできます。シェア機能で生成されるのは普通のテキストなので、LINE等で送れば相手もそのまま読めます。ただし相手のアプリに取り込めるのはアプリを持っている人だけです。
Q
AI版とレシピをやり取りできますか？
できます。シェアのテキスト形式は両版で共通なので、AI版で書いたレシピをスタンダード版で受け取ることも、その逆もできます。
Q
ブラウザのキャッシュを消すとどうなりますか？
レシピデータが消えます。大切なレシピは定期的にエクスポート（設定 → バックアップ）しておくことをおすすめします。
Q
機種変更するときはどうすればいい？
① 古い端末で「📤 エクスポート」→ JSONをクラウド（Googleドライブ等）に保存 → ② 新しい端末でアプリHTMLを開く → ③ 設定から「📥 インポート」でJSONを選ぶ、で引っ越し完了です。
Q
JSONとバックアップHTMLの違いは？
JSON = アプリに読み戻して編集を再開できる引っ越し用データ。バックアップHTML = アプリなしでもブラウザで開ける閲覧専用ファイル。普段のバックアップはJSON、家族と共有したい時はHTML、と使い分けてください。
Q
クラウドを何も使ってないけど大丈夫？
Googleアカウントがあれば、Googleドライブが無料で15GB使えます。iPhoneなら初期設定でiCloud Driveが有効になっていることが多いです。バックアップの保存先として使ってください。
